## **1. Создайте свой кастомный образ nginx на базе alpine**

Репозиторий Dockerhub c образом [https://hub.docker.com/repository/docker/usernam335/otus-nginx/general](url)\
Загрузить образ из репозитория:

    sudo docker login
_____________________________________________________________________________________        
    sudo docker pull usernam335/otus-nginx:alpine-latest

Запустить контейнер:

    sudo docker run -d --restart always -p 8090:80 usernam335/otus-nginx:alpine-latest

Проверка:

    sudo docker ps 

Посмотреть кастомную страницу:

    curl localhost:8090

## **2.Определите разницу между контейнером и образом**

1. Контейнер - изолированная среда для запуска приложений.\
Образ - неизменяемый файл-шаблон для запуска контейнера

2. Можно ли в контейнере собрать ядро?\
Собрать ядро Linux внутри контейнера можно, но собранное внутри контейнера ядро нельзя загрузить и использовать прямо внутри этого же контейнера. Оно будет работать поверх ядра хост-системы
